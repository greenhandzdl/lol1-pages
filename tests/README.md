# 测试

```bash
npm test          # 全部 157 项（约 2.5 分钟）
npm run test:fast # 页面冒烟 + 数据校验（约 40 秒）
npm run test:data # 纯数据，不起浏览器（约 1 秒）
```

首次运行会自动在 `.cache/pyenv/` 建虚拟环境并装依赖，换机器不用手动装。
需要 `python3` 和 `node`；无显示器环境会走 `xvfb-run`。

## 这些测试为什么存在

不是"为覆盖率写测试"。每一条都对应一次真出过的问题，或者一类
"错了也不报错"的静默失败。

| 文件 | 挡住什么 |
| --- | --- |
| `test_pages.py` | 页面打不开、横向溢出、JS 报错、**导航顺序不一致**、主题切换失效、**主题芯片筛不出人**、`?tag=` 老链接变空白、**关 JS 后首页是空壳** |
| `test_data.py` | 数据字段缺失、关系指向不存在的人、**角色永远测不出来**、**story 抄了 bio**、**「她的一天」缺段或时段乱序** |
| `test_crosscheck.py` | JS 与 Python 两份算法算出不同结果 |
| `test_store.py` | 存档迁移丢数据、坏存档白屏、隐私模式下崩溃、清空不可逆 |
| `test_play.py` | 测验走不完、配对判定错、玩法切换页头不同步 |
| `test_css.py` | **引用了不存在的 CSS 变量**、括号不配对、暗色主题漏定义、**正文文字对比度不足 4.5:1** |
| `test_a11y.py` | 图片缺 alt、按钮无名、焦点不可见、无障碍状态不同步、**关系网节点键盘进不去** |
| `test_glyphs.py` | **元素图形缺画/多画**、**图形坐标越界**（会被 viewBox 裁掉）、accent 对比度不足、**12 个人的 accent 糊成同一个色**、CSS mask 缺 xmlns（静默变灰方块） |

## 三条踩过的坑

**CSS 变量写错不会报错。** 有一版用了 8 处 `var(--ink-1)`，这个变量不存在，
`color-mix()` 整体失效，进度条轨道直接消失。页面不报错、不溢出、JS 也没事，
浏览器测试全绿。所以 `test_css.py` 直接读源码做静态检查。

**平局处理不一致。** JS 用 `if (s > best)` 严格比较（并列取先出现的），
Python 的 `max([(sim, i)])` 在并列时按第二元排序（取后出现的）。
同一道题算出两个结果。`test_crosscheck.py` 让 Node 真跑一遍线上逻辑对答案。

**一次挂多个 dialog handler 会互抢。** 第二次点击时两个 handler 都触发，
报 "already handled"。改成单个 handler + 可变标志。

**accent 是算出来的，但算错了也不报错。** 角色 `palette` 是浅粉浅紫，
直接当文字色对比度只有 1.3:1，`accent.js` 按 WCAG 压到 4.6:1 以上。
压过头就 12 个人糊成同一个深灰（实测 4.5:1 时樱井小春和花音的通道差只有 2/255），
所以 `test_glyphs.py` 按"亲戚组"检查色相分离 —— 书织和奶油的 palette 本来就是
同一个灰杏色，硬掰开等于给奶油凭空换色。

**对比度是纯算术。** `--ink-3` 曾经是 `#a98897`，对 `#fff8f4` 只有 3.00:1 ——
用它画的小字（完成度标签、画师名、关系备注）在浅色主题下是糊的。
页面不报错、不溢出、JS 没事，浏览器测试全绿。现在 `test_css.py` 用 WCAG
相对亮度公式直接从 CSS 取值重算（`test_contrast_tokens`、
`test_contrast_on_surface`），改回旧值立刻红。

**筛选"看起来能用"和"真能筛出东西"是两件事。**
首页曾经用 tags 当筛选项，35 个标签里 34 个只对应一个人 ——
点下去剩一张卡，用户以为坏了。`test_theme_chips_filter` 拿芯片上印的人数
去比实际筛出来的卡片数，对不上就红。

## 不做的事

**不做像素级视觉回归。** 字体渲染在不同机器上差几个像素就会红，
产出的噪音远大于它能发现的问题。视觉靠人看，逻辑靠测试。

**不做覆盖率统计。** 数字好看和测试有用是两件事。
